🔍 What is Guardian?

Guardian is a lightweight USB security utility built for Windows. It doesn't replace your antivirus—it complements it by focusing specifically on USB ports, real-time file creation, and user-controlled threat management.

While traditional antiviruses are heavy and slow down your PC, Guardian sits silently in the background, using almost zero CPU. It catches threats before they can execute, giving you full control over what stays and what gets removed.

  • ⚡ Instant USB Virus Scanner: The moment you plug in a USB drive, Guardian detects it and offers an instant scan—catching malware before it spreads.
  • 📜 USB History Tracker: Maintains a SQLite database logging every USB ever plugged in, including Drive Letter, Volume Label, File System, and Timestamp. Exportable to CSV.
  • 👁️ Real-Time File Monitor: Watches your Desktop, Downloads, and Temp folders. If a suspicious file (like `.exe`, `.vbs`, `.js`, etc.) appears, Guardian alerts you immediately.
  • 🛡️ Full Control Quarantine: When threats are found, you get a dialog box allowing you to Select All, Deselect All, or choose specific files to Quarantine. You have the final say.
  • 🤝 Trust (Exceptions) System: Found a false positive? Click "Trust". The file is added to a secure exceptions list and will never be flagged again.
  • 📊 Live Threat Counter & Stats: Tracks exactly how many threats Guardian has blocked for you since installation. Includes a detailed "Stats" dialog showing total scans, quarantine count, and more.
  • 🔔 Daily Scan Reminder: Guardian politely reminds you once a day to run a full system scan, ensuring your PC stays safe without nagging you.
  • ⬇️ Background Mode (Tray): Click "Run in Background" to minimize Guardian to the system tray. It continues monitoring without cluttering your taskbar.
  • 📄 Read-Only Activity Log: All actions are logged in real-time. The log is locked for editing, so users can't accidentally delete important security events.
